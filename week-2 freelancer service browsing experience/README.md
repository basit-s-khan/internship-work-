# CODIORA — Week 1 Enhanced Marketplace

## Files
- `index.html` — landing page
- `services.html` — freelancer/service browsing experience
- `service.html` — dynamic service details page
- `style.css` — shared responsive design system
- `app.js` — service data, search, filtering, sorting, navigation and UI states
- `assets/` — local SVG profile images

## Features
- Search by freelancer, service, skill, or category
- Category filtering with URL query support
- Sorting by relevance, price low→high, price high→low, and highest rated
- Dynamic reusable service cards generated from JavaScript data
- Dynamic service detail page using `service.html?id=...`
- Save-service state
- Contact-freelancer modal
- Responsive desktop/tablet/mobile layouts
- Consistent CODIORA color palette

## Run
Open `index.html` in a browser. For best results, use a local static server such as VS Code Live Server.
