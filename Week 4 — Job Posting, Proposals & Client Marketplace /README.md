# Paklaunce — Week 4

**Only Freelance Marketplace in Pakistan**

Week 4 extends the Week 3 frontend with a client marketplace where clients can post jobs and freelancers can discover projects and submit proposals.

## Pages
- `index.html` — homepage with latest jobs
- `services.html` — freelancer/service marketplace
- `jobs.html` — Find Jobs marketplace with search, category filtering and sorting
- `job.html` — dynamic job details page
- `post-job.html` — client job posting form
- `submit-proposal.html` — freelancer proposal form
- `my-proposals.html` — proposal dashboard with Pending, Accepted and Rejected states
- Week 3 profile/service pages remain available

## Week 4 functionality
- Dynamic job data
- Job search
- Category filtering
- Budget and proposal sorting
- Job details
- Client job posting
- Form validation
- Proposal submission
- Proposal status management
- LocalStorage persistence
- Responsive desktop/tablet/mobile layouts

## Run
Open `index.html` in a browser or use VS Code Live Server.

No backend is required for this frontend milestone. Jobs and proposals are persisted in browser LocalStorage.
