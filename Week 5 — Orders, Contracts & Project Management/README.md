# Paklaunce — Week 5: Orders, Contracts & Project Management

## Week 5 workflow
Proposal → Accepted → Order/Contract → Project Progress → Delivery → Completed

## New pages
- `orders.html` — My Orders / Projects dashboard
- `project.html?id=PKL-1001` — dynamic project details
- Existing Week 4 pages remain available.

## Features
- Active and completed project cards
- Project status: Pending, In Progress, Submitted, Completed, Cancelled
- Project budget and deadline
- Client/freelancer information
- Progress indicators
- Milestones and task completion
- Client View / Freelancer View
- Delivery/submission UI
- Approve Delivery / Request Changes states
- Complete Next Milestone interaction
- Project activity feed
- Filters for status and role
- LocalStorage persistence for project state
- Responsive desktop/tablet/mobile layout

## Demo
Open `index.html` or `orders.html` with a local static server such as VS Code Live Server.

## Notes
This is a frontend-only Week 5 implementation. Payment processing, authentication, real messaging, file uploads, and server-side contracts can be connected in later weeks.
