# Paklaunce — Week 3

Only Freelance Marketplace in Pakistan.

## Week 3 features
- User Profile page
- Edit Profile with validation and localStorage
- Freelancer Profile
- Create Service/Gig form
- My Services dashboard
- Service Details page
- Dynamic service creation/deletion
- Search, category filtering and sorting carried from Week 2
- Responsive desktop/tablet/mobile UI
- Consistent dark navy, electric blue and mint palette

## Run
Open `index.html` directly, or use VS Code Live Server.

No backend is required. Profile and created services are stored in browser localStorage for this frontend demonstration.
